# Nexo — Pre-entrega de proyecto

Sitio de muestra de accesorios tecnológicos, creado con HTML y CSS para practicar estructura semántica, navegación interna, Flexbox, Grid, diseño responsivo y formularios.

## Contenido

- `index.html`: secciones Inicio, Productos, Reseñas y Contacto; navegación en una lista desordenada.
- `styles.css`: estilos, Google Fonts, fondos y media queries.
- `assets/`: ilustraciones SVG locales para el contenido multimedia.

## Activar el formulario con Formspree

1. Creá un formulario gratuito en [Formspree](https://formspree.io/) y verificá tu correo según sus instrucciones.
2. Copiá la URL del formulario, que tiene el formato `https://formspree.io/f/XXXXXXXX`.
3. En `index.html`, reemplazá `https://formspree.io/f/TU_ID_DE_FORMSPREE` en el atributo `action` por esa URL. No uses una dirección de correo en el atributo `action`.
4. Publicá el sitio y enviá un mensaje de prueba desde la URL pública para confirmar la recepción.

El formulario HTML ya incluye método POST y campos obligatorios de nombre, correo y mensaje. **Hasta reemplazar el identificador, no puede recibir mensajes.**

## Ver y publicar

Abrí `index.html` en el navegador para revisar el diseño. Para publicar con GitHub Pages: subí el contenido de esta carpeta a un repositorio y, en **Settings → Pages**, elegí **Deploy from a branch**, `main` y `/ (root)`. Guardá y copiá la URL publicada (`https://USUARIO.github.io/REPOSITORIO/`). También podés subir la carpeta a Netlify mediante su opción de despliegue manual.

Reemplazá en el campus la URL de ejemplo por la URL pública real. **El archivo ZIP por sí solo no constituye la entrega alojada.**

## Créditos

Ilustraciones SVG originales incluidas en el proyecto. Tipografías DM Sans y Space Grotesk servidas por Google Fonts. Las reseñas y los productos son datos de demostración para este proyecto académico.
